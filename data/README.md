# data — 설정 · 지도 · 가정값 (JSON)

JSON은 주석을 달 수 없어서 파일 안의 `_note` 키와 이 문서로 설명한다. **숫자 대부분은 가정값**(팀 확인 필요)이다.

| 파일 | 내용 | 바꾸는 곳 |
|---|---|---|
| `sectors.json` | 현장 구성: 호퍼 A·B·C(베이 3개씩, 베이마다 원료 1종) · 대기장 · 계근대 · 원료야드 위치, 경로와 거리(OSM 실측), 카메라 연결, 안전 경고 규칙(`safety`, 합성 작업자 `synthetic` 기본 꺼짐) | `tools/build_map.py` |
| `settings.json` | 운영 기준: 혼잡 기준(%), 목표 대기, 지연 배수, 호출 여유, 구내 제한속도, **비용 단가**(대기 ₩30,000/시간 · 호퍼 유휴 ₩200,000/시간), 시뮬레이션 시작 시각 · 배속, 차량 수 · 원료 비율 | 설정 화면(저장하면 `assumptions.json`) |
| `std_times.json` | 원료별 표준 하차시간(분) — 시뮬레이터의 '실제' 하차시간 기준 | 직접 |
| `assumptions.json` | 설정 화면에서 바꾼 값과 변경 이력(git 제외) | 설정 화면 |
| `cams.json` | 영상 채널 4개(CAM-01~04): 영상 파일 · 크기 · 영상 픽셀 구역(하차 · 대기 · 위험), m/px, 시간 배율, **아차사고 규칙**(①덤프 반경 ②후진 경로 ③대기장 접근), 합성 사람 스위치(`stand_in`, 기본 꺼짐) | 설정 › 구역(ROI) 편집기 |
| `rois.json` | 영상이 없을 때 쓰는 시뮬레이션 그림(1920×1080)의 구역 | 직접(보기 전용) |
| `site_map.json` | 관제 맵 평면도 배경(OpenStreetMap 포항제철소 주변, ODbL) | `tools/build_map.py --fetch` |
| `stand_in.json` | 합성 사람 궤적(호퍼 영상에 사람이 없어 R15 시연용으로 둔 것) — 지금은 꺼져 있음 | 직접 |
| `demo.json` | 운영 분석 '시연 시나리오': 고정 시드 + 정해진 돌발(호퍼 정지 · 긴급 반입 · 복구) | 직접 |
| `auth.db` · `events.db` | 계정 · 알림 · 이벤트 기록(SQLite, git 제외) | 서버가 씀 |
