## 6. 알림 이력 — `#alerts`

알림 → 제안 → 처리(승인 대기·실행·무시·확인·오탐지·자동 실행) → 예상 효과(제안 때) vs 실제 효과(베이 진입 뒤) · 퍼널 · 무시한 제안도 실제(대개 0분) 기록 · 순번 변경은 +분 · 안전 행(금액 없음). ✅ 대부분 · 🔧 처리 상태 이름을 ⑤ "알림" 표에 맞춤.
