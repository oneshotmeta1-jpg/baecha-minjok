# 계정 · 로그인 (R11)

## 처음 켤 때

1. `py app/server.py` (또는 `서버켜기.bat`) → http://127.0.0.1:8000 → 로그인 화면.
2. **회원가입 → 관제 담당자**로 가입하면, 관리자가 아직 없을 때 첫 관제 담당자는 **관리자로 바로 사용**된다.
3. 그다음 가입하는 관제 · 현장 담당자는 **승인 대기**. 운전자는 차량번호를 확인하면 바로 사용.

로그인 없이 지금처럼 쓰려면 `py app/server.py --no-auth` (시연용 · 관제 담당자로 본다).
확인용 서버 `--check`는 계정도 메모리에만 둔다(껐다 켜면 사라짐).

## 승인 · 계정 관리 (설정 › 가입 승인 탭이 생기기 전 임시)

```bash
py tools/users.py list                    # 목록 (비밀번호는 안 보임)
py tools/users.py approve F2001           # 승인 대기 → 사용
py tools/users.py reject F2001            # 반려
py tools/users.py admin P1001             # 관리자로
py tools/users.py add field F2002 김현장   # 비밀번호는 입력창에서
```

## 역할과 화면 · 권한 (app/auth.py `RULES`)

| 역할 | 로그인 아이디 | 열리는 화면 | 할 수 있는 것 |
|---|---|---|---|
| 관제 담당자 | 사번 | PC 관제 화면 `/` | 전부(시연 · 기준값 · 내보내기 · 순번 승인 · 안전 확인) |
| 현장 담당자 | 사번 | 모바일 `/m/` | 담당 하역장만: 조회, 순번 승인 · 변경, 안전 확인 · 오탐지, 알림 확인 (`/api/field/*`, 실시간 `/ws/m`) |
| 운전자 | 차량번호(예: 82가 1234) | 모바일 `/m/` | 자기 차량만: 운행 등록 · 이동 시작 · 도착 · 멈췄어요 (`/api/driver/*`, 실시간 `/ws/m`) |

- 로그인 안 하면 API는 401, 화면은 로그인으로. 권한 없는 API는 403. 관제 화면 API와 실시간(`/ws`)은 관제만(R12부터 현장은 `/api/field/*`로 담당 하역장만).
- 관제 담당자가 `/m/`을 열면 현장 화면 미리보기(전체 하역장).
- 영상 넣기(`/api/ingest`)는 이 PC에서 보내면 로그인 없이 된다. 다른 PC에서는 서버를 켤 때 환경변수 `DOCK_INGEST_TOKEN`을 정하고 요청 헤더 `X-Ingest-Token`에 같은 값을 넣는다.

## 보안 처리

- 비밀번호: 솔트(16바이트) + scrypt 해시만 저장. 평문 저장 · 로그 출력 없음. 8자 이상 · 영문+숫자.
- 세션: HttpOnly 쿠키(SameSite=Lax). DB에는 토큰의 SHA-256만. "로그인 유지" 14일, 아니면 12시간(브라우저 닫으면 끝).
- 같은 아이디 5번 틀리면 1분 잠금(맞는 비밀번호도 거절), 성공하면 초기화.
- 같은 와이파이 시연(--lan)은 http라 쿠키 Secure는 꺼 둔다. HTTPS로 열 때 켠다.
- 계정 DB `data/auth.db`는 git에 올리지 않는다(`*.db`).
