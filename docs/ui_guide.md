# 화면 기준 (R7)

관제 대시보드(web/index.html)와 앞으로 만들 모바일 화면(/m/driver, /m/manager)이 같이 쓰는 크기·간격·스크롤 기준입니다.
값은 `web/index.html`의 `:root` CSS 변수와 같습니다. 바꿀 때는 두 곳을 같이 고칩니다.

## 1. 스크롤 정책

| 화면 | 정책 | 이유 |
|---|---|---|
| 관제 화면 (`#monitor`) | **한 화면 고정** (1920x1080에서 페이지 스크롤 없음) | 관제실 모니터에 띄워 두고 한눈에 보는 화면 |
| 관제 화면 › 다음 호출 | 카드 안에서만 세로 스크롤 · 최소 높이 250px(상위 3건 이상 항상 보임) | 호출이 많아도 맵·호퍼 카드가 밀리지 않게 |
| 하역장 상세 (`#cam/…`) | 한 화면 고정 | CAM을 크게 보는 화면 |
| 순번·배정 · 운영 분석 · 알림 이력 · 설정 | **페이지 세로 스크롤** (`body.free`) | 표와 카드가 내용만큼 늘어나 답답하지 않게. 오른쪽 요약 열은 스크롤해도 따라옴(sticky) |
| 알림 패널 · 바꿔보기 패널 | 패널 안에서만 스크롤 | 겹쳐 뜨는 패널 |

## 2. 간격 · 글자

| 이름 | 값 | 쓰는 곳 |
|---|---|---|
| `--gap` | 14px | 카드와 카드 사이 |
| `--pad` | 18px | 카드 안 좌우 여백 |
| `--fs-title` | 16px | 카드 제목 |
| `--fs-body` | 14px · 표 13.5px | 본문, 표 |
| `--fs-sub` | 12.5px | 보조 설명(`.cap`, `.sub`), 표 머리 |
| `--fs-num` | 28px (관제 카드 26px) | 혼잡도 %, KPI 숫자 |
| 표 칸 | 9px 10px | `td` 안 여백 |
| CAM 채널명 · 박스 라벨 | 17~24px (캔버스 기준, 타일에서도 12px 이상으로 보이게) | CAM 타일 · 하역장 상세 |
| 다음 호출 | 차량번호 15px · 호출 시각 16px | 관제 화면 오른쪽 열 |

- 숫자는 `tabular-nums`(자리 맞춤)를 씁니다.
- 상태는 색만으로 구분하지 않고 글자(원활·주의·혼잡·정지, 승인 대기 등)를 같이 둡니다.

## 3. 버튼 · 터치 크기

| 대상 | 최소 크기 |
|---|---|
| PC 버튼 (`.pill-btn`) | 높이 36px (`--hit`) |
| PC 작은 버튼 (`.mini`) | 높이 28px · 좌우 12px |
| **모바일 버튼** (다음 라운드) | **높이 44px 이상, 버튼 사이 8px 이상** · 주요 동작(출발 · 도착 · 승인)은 화면 폭 전체 |
| 모바일 글자 | 본문 16px · 보조 14px · 차량번호·호출 시각 20px 이상 |

## 4. 화면 확인

- 1920x1080에서 `bash tools/capture.sh <접두어>`로 다섯 화면을 찍어 `docs/screens/`에 남기고, 바꾸기 전후를 나란히 봅니다.
- 확인용 서버는 `py app/server.py --port 8001 --check`(메모리에서만 돌아 켜 둔 공유 서버와 겹치지 않음).
