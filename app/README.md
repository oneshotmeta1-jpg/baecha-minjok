# app — 서버 · 운영 상태 · 시뮬레이터

`python app/server.py` 하나로 관제 화면(/) · 모바일(/m/) · CAM 새 창(/cams) · API · WebSocket이 함께 뜬다.

| 파일 | 하는 일 |
|---|---|
| `server.py` | **FastAPI 서버(입구).** 화면 파일 제공, `/api/*` 엔드포인트, WebSocket `/ws`(관제 전체 상태) · `/ws/m`(모바일, 사람마다 거른 상태 1초마다), 0.1초마다 시뮬레이션을 돌리는 ticker. 실행 옵션: `--lan` `--port` `--video`(영상 모드) `--check`(메모리만, 확인용) `--no-auth` |
| `runtime.py` | **운영 상태의 중심.** 추천 시뮬레이션과 FIFO 기준선 시뮬레이션을 나란히 돌리고, 담당자 행동(승인 · 순번 변경 · 안전 확인 · 운전자 확인 …)을 기록해 다시 계산할 때 그대로 재생한다. 효과(대기 절감 분 · 금액), 운영 분석, 알림 이력, 설정 화면 데이터, 운전자 · 현장 화면 데이터(`driver_view` · `field_view` · `zone_view`)를 만든다 |
| `sim.py` | **시뮬레이터.** 덤프트럭 순환(계근대 → 대기장 → 호출 · 이동 → 호퍼 대기선 → 하차 → 출차 → 원료야드 재상차), 안전 경고, 하차 지연, 영상 아차사고 재생, 기사 앱 차량의 하역 완료 확인 대기. 영상 모드(`driven`)에서는 `/api/ingest` 이벤트로만 움직인다 |
| `engine.py` | **순번 · 배정 공식(순수 함수).** 혼잡도, 예상 하차 시작, 호출 시점, 순번 변경 영향(`change_impact`). 공식 근거는 `PLAN.md` |
| `auth.py` | **계정 · 로그인 · 권한.** scrypt 비밀번호 해시, HttpOnly 세션 쿠키, 역할별 권한표(`RULES`: 관제 · 현장 · 운전자), 가입 승인 · 관리자 기능(승인 · 반려 · 비밀번호 초기화 · 삭제) |
| `notify.py` | **알림.** 이벤트 → 받는 사람(역할 · 담당 하역장 · 동의), 1분 중복 방지, 안전 경고 30초 재전송(최대 3번), 받음 · 읽음 · 조치 시각 |
| `cams.py` | **영상 채널.** `data/cams.json` + `영상/` 폴더 → 채널마다 영상/시뮬레이션, 시뮬레이션 모드용 실제 영상 아차사고 목록(`video_near_miss`) |
| `rois.py` | **구역(ROI) 편집 API.** 설정 › 구역(ROI)에서 관리자가 그린 구역을 검사해 `data/cams.json`에 저장 |

## 데이터 흐름

```
(시뮬레이터 또는 영상 · 앱 이벤트 /api/ingest) → sim.py 상태 → runtime.py(추천 vs FIFO · 효과 · 기록)
   → server.py → WebSocket /ws (관제) · /ws/m (모바일) · /api/* → web/ 화면
```

이벤트 형식과 종류는 `docs/events.md`, 권한은 `docs/auth.md`, 알림은 `docs/notify.md`.
